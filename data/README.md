# Data

Synthetic mailboxes. Every company, person, number and date is made up.

- `examples/`: one small worked mailbox per finding class, with the deciding clause, the arithmetic and the expected report.
- `scenarios/`: the practice mailbox (two batches, about 160 documents, 30 scenarios), its feedback file and the answer key `make grade` scores against.
- `exam/`: a second mailbox with a new customer, carrier and invoice layout, and no answers. `make sheet` runs it.
